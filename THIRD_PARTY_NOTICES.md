Its [upstream MIT text](resources/licenses/upstream/react-remove-scroll-bar-MIT.txt) is retained from [upstream commit 7301c160fda44cb8cf2b9fdfde61efad35736196](https://github.com/theKashey/react-remove-scroll-bar/blob/7301c160fda44cb8cf2b9fdfde61efad35736196/LICENSE).

## Electron runtime / Electron 运行时

The macOS application embeds Electron 45.0.0. Its [MIT license](resources/licenses/electron-MIT.txt) is included here. Electron's runtime also contains Chromium, Node.js, V8, and other third-party components with separate licenses. The exact runtime distribution supplies the full aggregate notices as LICENSES.chromium.html; electron-builder preserves that file and LICENSE.electron.txt in Diffolio.app/Contents/Resources/. Preserve both files when redistributing the app. This npm inventory does not replace those runtime notices.

macOS 应用内嵌 Electron 45.0.0，其 MIT 许可见上方链接。Chromium、Node.js、V8 等运行时组件的完整声明由对应 Electron 发行包提供，打包后保留在应用 Contents/Resources/ 下的 LICENSES.chromium.html 和 LICENSE.electron.txt。再次分发时须一并保留；本依赖清单不替代运行时声明。

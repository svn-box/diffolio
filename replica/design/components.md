# Implemented components

This inventory records the shipped compact Diffolio surface after the approved welcome/comparison separation and source-interaction correction on 2026-10-27. It complements [docs/DESIGN.md](../../docs/DESIGN.md) and the schema-version-2 visual specimens in `.impeccable/design.json`. The source is React/TypeScript with semantic CSS; shadcn's composition pattern is reused for the font-size Combobox without a Tailwind runtime. Variant names present in a helper are not treated as finished styles unless the shipped surface uses them.

## Sources and authority

- `src/renderer/src/tokens.css`: semantic light/dark colors, fonts, shadows, control radius and toolbar height.
- `src/renderer/src/styles.css` and `styles/`: ordered layout, focus/hover states, welcome-local palette, neutral rail states, source controls, immediate previews and native dialog. Current source and the last two surface-contract sections determine the measurements below.
- `src/renderer/src/state/`: Zustand sessions, drafts, preferences, recents and task feedback; `components/shell/`, `Statusbar.tsx`, `EditingBar.tsx`, `Pathbar.tsx` and `SettingsDialog.tsx` own the corresponding UI and native-dialog portal container. `App.tsx` composes the window.
- `src/renderer/src/components/Home.tsx`: original geometric stage, navigation, real recents and entry actions.
- `src/renderer/src/components/CompareSetup.tsx`: independently droppable source inputs, separate Choose/Paste actions, cached file/folder modes and supplied-content preview.
- `src/renderer/src/components/TextCompare.tsx`, `SourcePreview.tsx` and `editor/`: CodeMirror lifecycle, read-only preview, editor preferences, syntax colors, chunk navigation and result editing. Editor snapshots stay outside Zustand.
- `src/renderer/src/components/ui/{button,popover,command,combobox}.tsx`: reusable shadcn composition adapted from SVNBox.
- `replica/design/tokens.json`, `tokens.css` and `contrast.json`: current workspace exports. The contrast report checks 92 workspace pairs with zero AA failures; it does not cover welcome gradients.

## Shadcn composition boundary

`Button` uses Radix Slot and class-variance-authority. Its exported API declares default/outline/ghost/destructive variants and default/sm/icon sizes, but the current shipped consumer is the explicitly styled `combobox-trigger`. Do not infer a complete visual variant catalog from those API names. The regular app actions above are styled semantic buttons.

`Popover` and `PopoverTrigger` wrap Radix primitives. `PopoverContent` defaults to a 5px side offset; font size aligns to the end of the trigger and passes `dialog.current` as its portal container. That container is necessary for the modal top layer and inherited appearance. The popup constrains its maximum height with Radix's available-height property.

`Command`, `CommandInput`, `CommandList`, `CommandEmpty`, `CommandGroup` and `CommandItem` wrap cmdk. The item highlight uses accent-soft; the committed value displays a violet check. Search and label/value keywords feed real filtering. Selection persists through the preference API and dismisses the popup. Escape is handled in the popover so it does not dismiss settings on the same key press. Framework-free sidecar specimens show appearance only; they do not reimplement Radix or cmdk interaction.

## Theme, accessibility and motion contracts

Workspace appearance is system/light/dark and reads semantic custom properties. The welcome intentionally overrides those variables locally and stays dark, including native controls. Its opaque graphite rail uses dedicated neutral navigation fills; it never inherits the shared violet hover fill. The rail and gradient belong only to welcome; source entry and comparison occupy the full window width. Settings inherits the current surface context; the dialog-contained popup inherits the same context.

Buttons and fields expose visible focus. Icon-only controls have accessible names; tabs, selected controls, status and alert feedback retain their respective semantics. Diff meaning uses labels, counts or symbols as well as color. Increased contrast replaces structural border color with input-border. Reduced motion disables animation and sets scroll behavior to auto. The only authored continuous animation is the one-second linear loading spin; no decorative transition timing is established.

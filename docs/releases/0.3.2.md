# Diffolio 0.3.2

## 中文

- 修复 macOS 窗口左上角关闭、最小化和最大化按钮偏上的问题：欢迎页、新建比较、对比页和设置窗口的原生按钮现在与各自标题栏垂直居中。
- 窗口缩放、恢复尺寸和切换深色外观后，按钮仍保持正确对齐。

## English

- Fixed the macOS close, minimize and maximize buttons sitting too high. Native controls now align vertically with the titlebar in the welcome screen, new comparisons, comparison views and Settings.
- Controls retain their alignment after resizing, restoring the window size and switching to dark appearance.

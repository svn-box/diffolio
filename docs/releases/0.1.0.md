# Diffolio 0.1.0

## 简体中文

首个个人自用的 macOS 版本，面向 Apple Silicon。应用界面使用简体中文，项目文档提供中英文版本。

### 功能

- 文本双栏与统一比较，包含语法着色、行内差异、搜索、差异导航、换行与不变区域折叠。
- 文件选择、独立 A/B 拖入和剪贴板输入；先加入一侧即可预览内容。
- 创建可编辑的结果副本，采用当前差异的 A 内容，支持跨布局撤销/重做和另存结果。
- 保存保留 UTF-8 BOM 与换行约定，并检查目标的外部变化；关闭未保存结果时可保存、放弃或取消。
- 文件夹内容比较、筛选、展开与文件下钻，支持任务进度和取消。
- 图片并排、共享缩放与平移；同尺寸图片支持分割滑块。
- 多比较会话、最近比较、系统/深浅主题和可搜索的字号选择。
- 原创 frosted-diff 原生图标与紧凑的 macOS 文档窗口。

### 安装

使用 `Diffolio-0.1.0-macOS-arm64.dmg`，打开后将 Diffolio 拖到 Applications；也可解压同名 ZIP 后放入 Applications。

本次本地候选包尚未使用 Developer ID 签名或 Apple 公证。它不代表已经完成公证的公开安装版本；以同目录 `release-manifest.json` 记录的状态为准。`SHA256SUMS` 用于检查文件完整性。

### 当前范围

文本支持 UTF-8，保留 BOM 及 LF、CRLF、CR 换行；打开和保存限制为单文件 16 MiB，目录扫描上限为 100,000 条。三方合并、Git/CLI 集成、Fluid 连线、忽略空白、目录同步和图片像素差异遮罩暂未包含。当前没有应用内自动更新。

## English

The first personal-use macOS release for Apple Silicon. The app interface is in Simplified Chinese; project documentation is available in English and Chinese.

### Features

- Side-by-side and unified text comparison, syntax highlighting, inline changes, search, change navigation, wrapping and unchanged-region folding.
- File dialogs, independent A/B drops and clipboard input, with an immediate preview of the first source.
- Editable result copies, applying the current change from A, undo/redo across layouts and explicit Save As.
- UTF-8 BOM and line-ending preservation, checks for external changes to the save destination, and save/discard/cancel on closing modified results.
- Folder content comparison, filtering, expansion and file drilldown, with progress and cancellation.
- Side-by-side images, shared zoom and pan, and a wipe slider for matching dimensions.
- Multiple comparison sessions, recent pairs, system/light/dark appearance and searchable font-size choices.
- Original native frosted-diff icon and compact macOS document windows.

### Installation

Open `Diffolio-0.1.0-macOS-arm64.dmg` and drag Diffolio to Applications, or extract the matching ZIP and move the app to Applications.

This local candidate has no Developer ID signature or Apple notarization. It is not a notarized public installer; its status is recorded in `release-manifest.json`. Use `SHA256SUMS` to verify file integrity.

### Current scope

UTF-8 text with BOM and LF, CRLF or CR line endings; 16 MiB per opened/saved file; up to 100,000 folder entries. Three-way merging, Git/CLI integration, Fluid connectors, whitespace-ignore rules, folder synchronization and image pixel-difference masks are not included. In-app automatic updates are not available.

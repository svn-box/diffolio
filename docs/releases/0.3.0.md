# Diffolio 0.3.0

## 中文

- 首个 Tauri 正式版，使用 Rust 和系统 WebKit，保留原有的比较界面、搜索、编辑结果、文件夹和图片比较流程。
- 提供经过 Developer ID 签名与 Apple 公证的 macOS Apple Silicon 安装包。
- 接入手动检查更新：检查 → 确认下载 → 重启安装。更新包必须通过签名与版本验证；未保存的结果或运行中的任务会阻止安装。
- 保留原有图标、浅色/深色外观、最近比较与偏好设置。

从 Electron 0.1.x 或本地 Tauri 预览版升级时，请下载 DMG 并拖入“应用程序”完成首次安装。Electron 的更新渠道不能安装 Tauri 更新包。从此版本开始，后续 Tauri 正式版可在应用内手动检查更新。

系统要求：macOS 13.3 或更新版本，Apple Silicon。设置保存在独立的 Tauri 数据目录，首次安装不会自动导入 Electron 或预览版的最近记录。

## English

- First production Tauri release, using Rust and system WebKit while retaining the comparison interface, search, editable results, folder and image comparison flows.
- Developer ID signed and Apple notarized installer for macOS Apple Silicon.
- Manual updates: check → confirm download → restart to install. Update signatures and signed versions are verified; unsaved results or running tasks block installation.
- Retains the original icon, light/dark appearance, recent comparisons and preferences.

To move from Electron 0.1.x or a local Tauri preview, download the DMG and drag Diffolio into Applications once. Electron's update channel cannot install Tauri archives. Future production Tauri releases can be checked for manually in the app.

Requires macOS 13.3 or later and Apple Silicon. Settings use a separate Tauri data directory; Electron/preview recent comparisons are not imported automatically.

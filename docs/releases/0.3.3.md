# Diffolio 0.3.3

## 中文

- 文件信息改为顶部信息按钮下的紧凑弹层，A/B 属性并列展示，打开时保持比较区完整宽度。
- 显示原始文件的名称、大小、类型、修改与创建时间、权限，以及文本的编码、BOM 和换行符；两侧不同的属性以蓝色强调。
- 支持图片和文件夹属性、两侧 Finder 定位、Escape 关闭及焦点返回；切换比较时关闭旧属性。无法取得的属性显示“—”。

## English

- Replaced the file-information sidebar with a compact popover beneath the toolbar Info button. A/B properties appear side by side without reducing the comparison width.
- Shows original filenames, exact sizes, types, modification and creation times, permissions, and text encoding, BOM and line endings. Differing values are highlighted in blue.
- Supports image and folder properties, per-side Reveal in Finder actions, Escape with focus return, and dismissal when switching comparisons. Unavailable properties display “—”.

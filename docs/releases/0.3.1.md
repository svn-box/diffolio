# Diffolio 0.3.1

## 中文

- 重做文本比较底栏：左侧显示选项、中间六个对称块操作、右侧差异导航。打开文件信息面板后，底栏仍对齐比较区域。
- 支持独立编辑 A/B 副本、双向复制当前差异，以及按 A 后 B、B 后 A 两种顺序保留双方。原始输入保持不变，修改需手动保存。
- 两侧各自保留撤销、重做和保存状态；再次点击对应铅笔可打开操作菜单，⌘S 保存当前侧。关闭时会检查两侧的未保存内容。
- 修复首部连续空行的块复制边界，保留空行、文件末尾换行、中文和 emoji 内容。
- 设置改为独立窗口，精简为通用与文本两类，支持外观选择和字号预览；设置窗口关闭后保留比较中的编辑。
- 入口新增本地更新日志和手动更新操作。原生“检查更新”菜单可恢复并聚焦最小化的主窗口。

统一布局支持写入 B 的块操作；点击编辑 A 会返回双栏布局，以使用 A 侧编辑和反向块操作。

## English

- Redesigned the text comparison footer with display options on the left, six symmetric block controls in the center and difference navigation on the right. The footer aligns with the comparison area when the file inspector is open.
- Edit independent A/B copies, copy the current difference in either direction, or keep both versions in A-then-B or B-then-A order. Original inputs remain unchanged; saving is explicit.
- Each side has independent undo, redo and save state. Click its pencil again for the action menu; Command-S saves the active side. Closing checks both sides for unsaved changes.
- Fixed block-copy boundaries around leading blank lines, preserving blank lines, end-of-file newlines, Chinese text and emoji.
- Settings now opens in an independent window with compact General and Text tabs, appearance choices and font-size preview. Closing Settings preserves comparison edits.
- Added local release history and manual update controls to the welcome screen. The native Check for Updates action restores and focuses a minimized main window.

Unified view supports block decisions targeting B. Editing A returns to split view for A-side editing and reverse block decisions.

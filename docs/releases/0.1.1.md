# Diffolio 0.1.1

## 简体中文

### 新增与改进

- 手动应用更新：从 Diffolio 菜单或设置检查版本，确认后下载，查看进度，再选择重启安装。未保存结果或进行中的任务会阻止安装。
- 参考 Kaleidoscope 整理文本搜索：路径栏下方使用共享搜索栏，提供 A/B 范围、前后匹配、计数、完成与中文选项，避免搜索只挤压一侧文稿。
- 支持区分大小写、完整单词和正则表达式；保留 ⌘F、⌘G、⌘⇧G、Enter、⇧Enter 和 Escape 操作。
- 搜索命中折叠内容时同步展开两侧；编辑结果后更新计数，重复查找保留已选范围。
- 防止较早的更新请求失败覆盖较新的下载状态，并完善只读文稿的键盘焦点。
- 补齐源码可用许可、第三方声明与许可全文。允许个人和公司内部免费使用；收费转售应用或修改版需另行获得书面授权。

### 安装与更新

本版本面向 macOS Apple Silicon。打开 `Diffolio-0.1.1-macOS-arm64.dmg`，将 Diffolio 拖到 Applications；也可解压同名 ZIP 后安装。

**0.1.0 用户需要手动安装一次本版本。** 安装 0.1.1 后，可通过应用菜单或设置手动检查后续版本。检查、下载和重启安装分别由你确认。

### 支持范围

文本支持 UTF-8、BOM 与 LF/CRLF/CR 换行；打开和保存上限为单文件 16 MiB，目录扫描上限为 100,000 条。三方合并、Git/CLI、Fluid 连线、忽略空白、完整块决策、目录同步和图片像素差异遮罩尚未包含。

## English

### New and improved

- Manual application updates: check from the Diffolio menu or settings, choose to download, follow progress, then restart to install. Unsaved results and active tasks prevent installation.
- A Kaleidoscope-inspired shared search bar below the file paths, with A/B scope, previous/next matches, counts, Done and localized options. Opening search keeps both document panes aligned.
- Case-sensitive, whole-word and regular-expression search, with ⌘F, ⌘G, ⌘⇧G, Enter, ⇧Enter and Escape support.
- Search reveals matches in folded regions on both sides, refreshes counts after result edits and preserves the selected scope when Find is invoked again.
- Older failed update requests no longer overwrite newer download state; read-only document keyboard focus is improved.
- Source-available licensing, third-party notices and full license texts are included. Personal and internal company use are free; paid resale of the app or modified versions requires separate written permission.

### Installation and updates

For macOS Apple Silicon. Open `Diffolio-0.1.1-macOS-arm64.dmg` and drag Diffolio to Applications, or install from the matching ZIP.

**Users of 0.1.0 must install this version manually once.** After installing 0.1.1, use the application menu or settings to check for later versions. Checking, downloading and restarting are separate actions you control.

### Supported scope

UTF-8 text, BOM and LF/CRLF/CR line endings; 16 MiB per opened/saved file; up to 100,000 folder entries. Three-way merging, Git/CLI integration, Fluid connectors, whitespace-ignore rules, the complete block-decision toolset, folder synchronization and image pixel-difference masks are not included.

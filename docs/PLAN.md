# Diffolio 开发计划

更新日期：2026 年 10 月 27 日。

Diffolio 面向个人自用的 macOS 场景。首先做出可以长期使用的文本对比工具，再增加目录、图片和 Git 能力。首个可自用版本必须能打开真实文件、清楚显示差异、编辑结果、撤销并可靠地另存为。

当前已构建可运行的 macOS 首版：文本比较、结果编辑与另存为已接通，基础目录和部分图片功能也已实现。当前阶段概览如下，未勾选项继续保留为后续任务。

已完成 [Kaleidoscope 功能与界面分析](../replica/recon.md)，并整理了 [44 项功能清单](../replica/features.csv)。以下阶段均以实际验收结果推进。

## 已确定的方向

| 项目 | 方向 |
| --- | --- |
| 名称 | Diffolio |
| 目标用户 | 个人自用 |
| 首要平台 | macOS |
| 桌面与界面 | Electron + React + TypeScript + Zustand |
| 文本视图 | 以 CodeMirror 6 和合并视图扩展为起点，先验证真实文件表现 |
| 数据 | 文件、偏好和有限的最近比较记录保存在本机 |
| 外观 | 简洁的文档窗口、清楚的字体层级、稳定的差异颜色和少量材质 |
| 功能顺序 | 文本比较 → 编辑与保存 → 目录比较 → 图片 → 三方合并与 Git |

技术方向来自前期分析。具体依赖版本、构建与打包工具在工程初始化时确认并锁定。Fluid 布局和三方冲突引擎分别安排工作，不依赖它们完成首版。

## 架构与状态约束

界面负责展示会话和发起操作；preload 只暴露需要的命令；主进程协调文件访问、窗口和后台任务。纯文本计算可使用编辑器自身的后台能力或 Web Worker；目录扫描与哈希等工作根据需要放入独立任务执行。

以下为建议的代码结构，工程初始化时再创建：

```text
src/
├── main/          窗口、菜单、文件访问、保存和任务协调
├── preload/       类型明确的界面接口
├── renderer/      React 页面、组件、编辑器集成和主题
├── shared/        会话、输入、差异结果和任务协议
└── workers/       按实际需要加入的后台计算
```

沿用分析中的 `ComparisonSession`、`FileReference`、`DiffHunk`、`FolderEntry`、`MergeDecision`、`Preferences`、`RecentEntry` 作为建模起点。原始输入快照、可编辑结果和差异视图分别保存状态；任务结果携带会话与内容版本，避免异步结果覆盖新的输入或编辑。

最近比较默认保存路径与比较选项，重新打开时读取当前文件；它不等于历史内容快照。剪贴板会话默认仅在当前运行期间保留，后续如需持久保存，再提供明确的保存操作。

## 验证与性能记录

优先验证会影响数据或用户判断的行为：差异范围、行内字符边界、块操作、撤销、编码与换行、写入失败、任务取消和过期结果。格式、布局和主题以实际窗口检查为主，交互连通性安排少量集成或端到端验证。

| 对象 | 样例与检查 |
| --- | --- |
| 文本正确性 | 相同、空输入、仅新增/删除、重复行、连续修改、中文、emoji、组合字符、长行、LF/CRLF、BOM |
| 保存可靠性 | 另存重开、撤销再保存、取消、只读目标、目标被外部修改、写入失败与临时文件清理 |
| 目录正确性 | 单侧文件、深层树、同大小不同内容、符号链接、权限失败、扫描中变化、取消后重新启动 |
| 窗口交互 | 文件拖入、模式切换、搜索、键盘焦点、未保存关闭提示、窗口缩放和深浅主题 |
| 性能观察 | 1/10/50 MB 文本与 1 万/10 万条目录逐档检查，记录输入类型、硬件、耗时、内存、取消响应和界面响应 |

性能档位用于发现瓶颈，不是已达到的支持上限。特别长行与大量重复行单独记录；有明确测量结果后再决定超大文件提示、计算预算或进一步优化。

### 按本机 Kaleidoscope 收紧尺寸

用户要求界面更精致紧凑后，实际启动并测量了 Kaleidoscope：欢迎窗口 964×564、侧栏 180 px、工具栏 52 px、彩色入口约 195 px。Diffolio 的默认窗口和入口采用这组比例；比较区的标签栏、路径栏、状态栏分别为 31、30、28 px，结果操作栏为 37 px，默认编辑字号 12 px。窗口仍可手动调整大小；参考截图在 `replica/screens/S01-welcome-live.png`。

### 欢迎导航与比较入口分离

再次查看 Kaleidoscope 的实际文档窗口，确认普通文件对比没有常驻导航侧栏。Diffolio 删除比较区的会话/最近记录侧栏，仅在欢迎页保留 180 px 导航；单个比较隐藏标签栏，多个比较通过标签切换。欢迎标题从主列左边开始，几何色带贯穿顶部 195 px，最近列表直接排列在下方；移除了重复标题、口号与额外的大型开始卡片。

新建比较使用独立的 A/B 输入界面。文本与图片共用文件入口，文件夹模式分别选择两侧目录，支持不同位置、取消后继续、各自拖入，以及两个来源齐备后自动比较。单文件连续打开会补齐另一侧；欢迎页往返保留未保存编辑与撤销。新的 `test:entry` 已验证这些流程及 964×564、880×540 窗口。

本轮实机参考：`replica/screens/S01-welcome-layout-live.png`、`replica/screens/S02-comparison-live.png`。当前界面与组件规范见 [DESIGN.md](DESIGN.md)。

### 按用户截图修正侧栏与来源状态
